# COVID-19 Vaccine Registration System 💉

A web-based platform designed to the COVID-19 vaccine registration process. This system allows users to register for vaccinations, select preferred vaccination centers, and track their registration status, while providing administrative tools to manage appointments and records.

---

## 🚀 Features

### **User Panel**
* **User Registration & Login:** Secure authentication for citizens.
* **National ID / Information Verification:** Input key details (NID, Date of Birth, Contact Information) to verify eligibility.
* **Center Selection:** Choose preferred hospital or vaccination center.
* **Vaccine Status Check:** Check real-time registration status and scheduled dose dates.
* **Download Registration Card / Certificate:** Printable PDF summary of registration/dose status.

### **Admin Panel**
* **Dashboard:** Overview of total registrations, vaccinated individuals, and available centers.
* **Manage Appointments:** Schedule and assign dose dates for registered citizens.
* **Manage Centers & Vaccines:** Add, edit, or remove vaccination centers and update stock levels.
* **Reports:** View and export detailed registration/vaccine logs.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP / Hack
* **Database:** MySQL

---

## 📋 Prerequisites

To run this project locally, ensure you have the following installed:

* **XAMPP** / **WAMP** / **LAMP** stack (with Apache and PHP support)
* **MySQL Database**
* Web browser (Chrome, Firefox, Edge, etc.)
